☁️ 云端账号与同步

本机库存功能无需账号即可使用。若要多人在不同设备共享同一份库存，需要 Firebase 项目。配置一次后，每位使用者用自己的邮箱和密码登录，登录状态会保留。

Firestore 安全规则：仅允许已登录用户读写共享库存。注册功能开放时，任何获得项目地址的人都可能注册；请仅分享给可信任的使用者。

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /inventory/{document} {
      allow read, write: if request.auth != null;
    }
  }
}
